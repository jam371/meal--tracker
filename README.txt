MEAL TRACKER - PWA

This folder is the installable web-app version of the Meal Tracker.

Files:
- index.html: app
- manifest.webmanifest: install/app metadata
- service-worker.js: offline caching
- icons/: home-screen icons

Next step: upload this folder to a web host such as GitHub Pages over HTTPS.
Then open the live URL on your phone and add it to the home screen.
